# Сохранённая сводка smoke-замеров пространственных индексов

Источник: README пространственного стенда в исходном проекте GalaxyCore. Короткие прогоны на Intel Core i9-11900, мир на 100 000 объектов, пакет из 1000 перемещений.

| Индекс | Время пакета |
|---|---:|
| Legacy PointOctree | ≈0,93–1,02 с |
| Dynamic AABB tree | ≈0,59–1,88 мс |
| Multilevel grid | ≈0,98–2,59 мс |
| Hybrid | ≈1,40–4,64 мс |

Это предварительные диапазоны для разных режимов движения. Полная таблица исходного прогона не сохранена; точные парные множители по концам диапазонов не вычисляются. Полный hybrid хранит и обновляет два индекса. Read-only запросы по равномерным точкам могут быть быстрее у прежнего octree.

В прогретом update path новых индексов аллокации не фиксировались. Выделение памяти при построении индекса и его постоянное хранение являются отдельными затратами.
