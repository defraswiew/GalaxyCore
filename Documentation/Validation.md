# Обновление публичного комплекта

Проверено 21 октября 2026 года на Windows x64. SDK собран из исходного коммита `05457725d339f68401ae9fde92b10ae91b7c4bf7`; точный состав и SHA-256 записаны в [SDK-MANIFEST.json](../Core/SDK-MANIFEST.json).

## Окружение и изменения

- Unity-проект переведён с 2021.3 на **Unity 6.3 LTS, 6000.3.24f1**, зависимости обновлены и закреплены в package lock.
- Сервер и управляемый шаблон UNIGINE переведены на **.NET 8**. Общие сообщения и клиентские DLL используют **.NET Standard 2.1**; Unity получает отдельный AOT-профиль.
- Обновлены API подключения, события и жизненный цикл адаптеров, сообщения авторизации, сериализация, сетевые переменные и синхронизация аниматора.
- Фабрика Unity привязывает исходную входящую сущность SDK, сохраняя владельца, начальные данные, transform и GalaxyVars.
- Серверные примеры переведены на Jitter2 и GPHB. Навигационные карты перепечены из сцен; абсолютные пути к дискам разработчика удалены.
- Удалены неиспользуемые ассеты, старые UI и экспериментальные заготовки. Рабочие ассеты из `_TMP` перенесены с сохранением GUID. Старые бинарные комплекты, дубли UNIGINE backup, IDE-состояние и генерируемые проекты исключены из поставки.
- Большая сгенерированная навигационная карта хранится в локальном `.artifacts`, а в Git остаются исходная сцена и конфигурация её слоёв.

Сетевой smoke запускает настоящий собранный Unity Player и временный .NET-сервер. Проверяются авторизация, создание комнаты и вход, список комнат, world sync, исходная сущность SDK в префабе, владелец, начальные Name/Hp и последующие изменения ServerTime. Имя и время в примере принадлежат серверу; Hp оставлен примером двусторонней переменной владельца.

Unity-сборки содержат предупреждения CS0649 о сериализованных полях, назначаемых редактором. Проверки Player выполняются в `-batchmode -nographics`: они проверяют сетевую логику и жизненный цикл, визуальная проверка отображения и платформы кроме Windows x64 в этот прогон не входят.

Команды повторения проверок приведены в [основной документации](README.md#проверки). Логи, отчёты, временные серверы и сборки находятся в игнорируемой `.artifacts`.

## Регрессия Add Force — 22 октября 2026

При входе в физическую комнату фабрика переживала смену сцены, а её отдельный staging-объект уничтожался вместе с Main. На исходном коде сетевой Player воспроизвёл исключение в `GalaxyNetworkInstantiator.OnGalaxyNetEntityInstantiate` при обращении к уничтоженному `GameObject.transform`.

Staging теперь является дочерним объектом фабрики и разделяет её жизненный цикл. Созданные представления перед активацией явно переносятся в текущую игровую сцену, чтобы уничтожаться при выходе из неё.

Новый сценарий `build/smoke-players.ps1 -AddForce` прошёл на Windows Mono и IL2CPP: два последовательных создания комнаты, вход в ExamplePhys, минимум три корректно привязанные сферы с обновлениями движения, выход в Main без оставшихся сфер и повторный вход с новым ID комнаты. Оба запуска завершились кодом 0. Проверки выполнялись в отдельной копии проекта, пока основной редактор оставался открыт.

## UNIGINE

Управляемый адаптер проверен компиляцией на .NET 8 с текущим Galaxy SDK и общими контрактами, используя временные заглушки поверхности API движка. Полная сборка и запуск движка требуют совместимого UNIGINE C# SDK и native deployment, которых в окружении нет. Исходные ресурсы сохраняют формат UNIGINE 2.15.1; их миграция и проверка на настоящем движке остаются отдельным необходимым шагом. Подробности — в [README шаблона](../Templates/UnigineClient/README.md).
