# Администрирование Galaxy

Актуальная серверная DLL содержит опциональный HTTP API GalaxyAdmin. Через него можно получать состояние сервера, клиентов, инстансов, сетевых сущностей, workers и физики, а также выполнять разрешённые операторские действия.

API активируется отдельно с прикладным resolver авторизации. Доступные возможности и права оператора описываются контрактом сервера; права чтения и записи проверяются на запросах. При интеграции задайте допустимую область доступа и ограничения сервиса в своём серверном приложении.

SDK поддерживает декларативные пользовательские данные и административные методы. Секреты авторизации должны приходить из конфигурации приложения, а не храниться в распространяемых DLL или репозитории.

Windows-приложение GalaxyAdmin — отдельный инструмент, описанный в патчноуте. Этот комплект поставляет SDK и игровые шаблоны; исполняемый файл desktop-приложения сюда не включён.
